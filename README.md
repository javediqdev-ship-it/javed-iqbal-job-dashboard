## Rules that never change

- Only real facts. Never invent a skill, a year, a company, a date, a project, a reference, a job, a company, pay or a link.
- One new tailored CV per job, checked against that job's requirements one by one. The skills list is not final — add per each job's requirements from Javed's full WordPress mastery. If a skill is uncertain, confirm with Javed first.
- For junior roles, do NOT over-mention seniority. No "Senior", no "Development Manager", no 11-year lead.
- Every tailored CV is about 2 pages, PDF for applying. Javed approves each CV first, then he applies himself.
- Remote only; USA, Canada, UK. More than $20/hour is best. Junior roles preferred and scored higher.
- Never skip a job: check every source, every listing, add every qualifying job. Dedupe by company + title + source link.
- Never use bots, scripts, scraping or automated Easy Apply on LinkedIn (ban risk).
- Keep every file in this repo updated. When anything changes, update the file here and push to GitHub.

## How to start work from this repo

1. Read `cv-master.md`, `cv-instructions.md` and `skills/` first.
2. Check `seen-jobs.md` before adding any job — never add a job twice.
3. Follow `skills/job-search-rules.md` for finding jobs and `skills/apply-process.md` for applying.
4. After any change, update the files here and push — this repo is the source of truth.
