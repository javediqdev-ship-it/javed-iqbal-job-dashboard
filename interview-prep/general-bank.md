# General Interview Bank — pass any company, not one job

Created 27 Nov 2026. This is the transferable core. One target job per session is the EXAMPLE; this bank is what transfers to every other interview.

## Core intro (60–90 seconds, adapt the last line per company)

11 years WordPress, 100+ websites, Development Manager at Rezolvemed (2015–2021) and Rising Revenue Solutions (2021–2026). Custom themes, custom plugins, custom dashboards. Then one line tying it to this company's work.

## Core technical answers (one real example each)

- Custom theme / plugin build from scratch
- Site speed and Core Web Vitals — measure first, then fixes in order
- WordPress security, backups and maintenance — routine, restore test, compromise response
- WooCommerce, Elementor, ACF, Gutenberg
- PHP / JavaScript / HTML-CSS / MySQL — real work, not definitions
- WCAG accessibility, GA4 / GTM, technical SEO, consent management

## 5 STAR stories (keep ready, reuse everywhere)

1. Production bug fixed under pressure
2. Tight / missed deadline delivered
3. Mentoring a developer / setting a technical standard
4. Difficult stakeholder / client
5. Site migration / rebuild

Each: situation → task → action → result, with a number where possible.

## Salary — general rule

- Junior / low-range roles: $20/hr = $3,200/mo = $41,600/yr.
- Senior / high-range roles (e.g. ClearCaptions $120,000–$139,000 + 5% bonus): leave pay blank on the form, discuss within their range in conversation. Never anchor low on a senior role.

## Gap bridges (honest, never a false claim)

- TypeScript, CI/CD, Salesforce, headless / Next.js, Divi — closest real work → what is new → 30-day plan.
- WordPress-related skills may be added without asking; skills clearly outside WordPress need Javed's one-time confirmation first.

## Adaptation drill (every session, 5 minutes)

Take one core answer and re-answer it for a different company type: senior platform role vs junior agency role vs support role. If it cannot adapt, it is not a core answer yet.
