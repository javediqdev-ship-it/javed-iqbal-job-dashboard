# Apply Process

How applying for a job works, step by step. This file is the living record — update it whenever new info about applying arrives.

## The flow

1. A job is found in the sweep and added to the dashboard (202 jobs; dedupe: never add the same job twice).
2. Save the FULL job description text to ~/workspace/javed-job-search/job-descriptions/<job-number>-<company>.md (metadata header + full text) — do this while the posting is live, because it disappears once the job closes. Needed later for interview preparation.
3. A tailored CV is made for that job (see cv-making.md).
4. The CV link is added to the dashboard CVs page.
5. Javed approves the CV.
6. Javed applies himself, using the tailored CV. (Since 26 Nov 2026: I fill the application in the browser and Javed clicks the final submit button himself.)
7. Upload the CV with a NEUTRAL filename (Javed_Iqbal_CV.pdf) — never a filename containing the company name, so the employer cannot tell from the filename that the CV was made for them. The internal files keep their descriptive names (javed-iqbal-cv-<company>.pdf); the uploaded copy is renamed to the neutral name first.
8. Interview: Javed is available at any time. Remote only — onsite is not possible, even for one day.

## Before applying — checks

- Remote status confirmed (the posting must really be remote; if the page does not say remote, confirm first).
- Pay is real employer pay, not an aggregator estimate.
- Posted date is real, not a re-aggregation date.
- Language or location barriers checked (example: a job needing strong French is a hard barrier — Javed's languages are English, Urdu, Punjabi).
- The job fits: WordPress or a related category Javed can do; remote; USA, Canada or UK.

## Job preferences

- Remote only. Full-time and contract both OK. Part-time also accepted.
- More than $20/hour is best; pay is otherwise not a filter.
- Junior WordPress and Junior Developer roles preferred and scored higher.
- The goal is an interview scheduled — the platform does not matter, the interview matters.
