# Javed Iqbal — Living Skill Base

This folder is the always-updated record of everything about Javed's job search: what he can do AND every instruction, rule and process he gives.

## Two kinds of files

1. Technical skill files — one file per skill (WordPress, WooCommerce, Elementor, PHP, and the rest). Each file says what Javed can actually do with it and where he used it. The list is NOT final — add skills per each job's requirements from his full WordPress mastery.
2. Instruction and process files — one file per topic:
   - cv-making.md — how CVs are made
   - apply-process.md — how applying works
   - job-search-rules.md — how jobs are found and scored

## The update rule

Whenever new information arrives — a new instruction from Javed, a new detail about the apply process, a new skill, a changed rule — update the matching file here AND the master CV together when the CV is affected. Never add a skill or a fact without evidence. Never let a file go stale.

## Rules for this folder

- One file per skill or topic. A skill gets a file only when it is real: it appears on the master CV or Javed has stated it as his own work.
- Never invent a skill, a tool, a level, a company, a date or a project. If a detail is not on the master CV and Javed has not stated it, it does not go in a file.
- Each skill file states: the skill, what Javed can actually do with it (only what the master CV and his stated experience support), and where it was used (Rezolvemed July 2015 – August 2021, Rising Revenue Solutions August 2021 – November 2026).
- Whenever a skill is added, changed or removed, update the file here AND the master CV at the same time, so the two never drift apart.
- Tailored CVs for individual jobs are built from these files plus the master CV. They highlight only the skills that job asks for; they never add a skill without Javed's confirmation when it is uncertain.
