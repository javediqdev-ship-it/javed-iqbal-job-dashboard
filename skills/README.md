# Javed Iqbal — Skills Record

This folder is the always-updated record of Javed Iqbal's skills for the remote WordPress job search.

## Rules for this folder

- One file per skill. A skill gets a file only when it is real: it appears on the master CV or Javed has stated it as his own work.
- Never invent a skill, a tool, a level, a company, a date or a project. If a detail is not on the master CV and Javed has not stated it, it does not go in a file.
- Each file states: the skill, what Javed can actually do with it (only what the master CV and his stated experience support), and where it was used (Rezolvemed 2015–2021, Rising Revenue Solutions 2021–November 2026).
- Whenever a skill is added, changed or removed, update the file here AND the master CV at the same time, so the two never drift apart.
- Tailored CVs for individual jobs are built from these files plus the master CV. They highlight only the skills that job asks for; they never add a skill that is not in this folder.
