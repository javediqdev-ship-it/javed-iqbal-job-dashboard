## Full job description

We are looking for a hands-on Website Manager to handle ongoing updates across a large portfolio of websites, primarily WordPress multi-site, along with a few Squarespace and Wix sites.

To be clear upfront: this is not a web developer role.

We don't expect custom coding or full site redesigns. Instead, we need someone who is technically savvy, has used these platforms to build sites, has a strong eye for clean design, and can reliably own page-by-page updates, new landing pages, and day-to-day site requests without hand-holding.

### What You'll Do

- **Manage incoming site requests:** Work directly with individual General Managers to handle requests for page edits, content updates, and new additions.
- **Build and update pages:** Create new pages, build out landing pages, and add or refresh individual page sections while keeping everything visually consistent with the existing site.
- **Handle operational updates:** Implement and test website forms, update privacy policies, and manage routine page-level housekeeping.
- **Advise and clarify:** Review requests before jumping in. If a request is missing details, doesn't make sense for the user experience, or could be executed better, ask clarifying questions and make practical recommendations.

### What We're Looking For

- **Platform proficiency:** Strong, hands-on experience working inside **WordPress** and **Squarespace**. Familiarity with **Wix** is a plus (or the ability to navigate it comfortably).
- **An eye for basic design:** You don't need to be a graphic designer, but you know what looks clean and readable and how to build it using the native builder and blocks.
- **High autonomy:** You manage your own queue, follow through on details, and don't wait to be told every step.
- **Clear communicator:** Masterful grasp of English is required. This role will be doing a lot of email communication internally and externally.

### What This Role Is Not

- Heavy front-end or back-end coding
- Ground-up website architecture or custom theme development
- Major site-wide layout overhauls

We anticipate this being a part-time role that is needed for 2-3 months.
