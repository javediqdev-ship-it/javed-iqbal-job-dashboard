## Role summary (paraphrased from the employer's posting)

Front-end developer on the web team owning all Edconic digital properties (school websites, landing pages, email templates, internal tools). Build and maintain custom WordPress themes across two stacks: modern block-based builds (ACF Blocks, core blocks, block patterns, theme.json) and classic themes on PHP templates, ACF and Sass. Translate Figma designs into responsive, accessible front ends; Git/GitHub workflows with pull requests and code reviews; performance, accessibility and SEO optimization including Core Web Vitals; support content teams with troubleshooting, training and documentation. Requirements: 4+ years of front-end development, semantic HTML/CSS/JavaScript/PHP and WordPress, custom themes with PHP templates and ACF, familiarity with block development and theme.json, Sass and build tools (Vite, npm named), WCAG, REST APIs and third-party integrations. Bonus items include WordPress multisite, custom post types and custom Gutenberg blocks, CRM platforms, GitHub Actions/CI/CD, GSAP, headless WordPress, GA4/GTM and A/B testing.
