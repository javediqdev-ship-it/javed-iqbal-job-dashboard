## Full job description

### Description

- Design, develop, and maintain custom WordPress functionality, including custom post types, taxonomies, metadata, plugins, and editorial workflows.
- Build and enhance Gutenberg blocks and editor tools.
- Develop and maintain REST APIs for web applications and digital platforms.
- Optimize WordPress performance, scalability, security, and maintainability.
- Collaborate with editorial, product, engineering, frontend, and stakeholder teams.
- Develop, maintain, and improve PHP and Python backend services and APIs.
- Support asynchronous processing, background jobs, and internal and external system integrations.
- Work with relational databases, caching technologies, and cloud-based services.
- Integrate third-party media, analytics, and content distribution platforms.
- Investigate production issues and improve reliability.
- Leverage AI tools for coding, debugging, testing, documentation, code reviews, research, refactoring, and automation.
- Evaluate and validate AI-generated code for correctness, security, performance, and maintainability.
- Write clean, documented, testable code; participate in code reviews and architectural decisions.
- Develop automated tests and follow CI/CD and deployment practices.
- Own features and technical improvements from design through deployment.

### Requirements

- Strong professional experience developing and maintaining production WordPress applications.
- Advanced knowledge of PHP 8+, object-oriented programming, modern PHP development practices, Composer, and dependency management.
- Experience building custom WordPress plugins, post types, taxonomies, metadata, and REST APIs.
- Hands-on experience developing custom Gutenberg blocks and working with the WordPress block editor.
- Understanding of WordPress security, performance optimization, caching, and coding standards.
- Experience designing, building, and maintaining RESTful APIs.
- Working knowledge of Python, including backend applications, APIs, or background processing services.
- Experience with relational databases such as MySQL or PostgreSQL.
- Familiarity with Docker, Git, automated testing, and CI/CD workflows.
- Ability to understand and modify React and JavaScript code, particularly in Gutenberg-based interfaces.
- Practical experience using AI-assisted development tools such as GitHub Copilot, ChatGPT, Claude, or equivalent solutions.
- Ability to critically review, validate, and improve AI-generated code.
- Understanding of responsible AI usage, including security, intellectual property, and data privacy.
- Strong troubleshooting, problem-solving, and communication skills.
- Ability to work independently and collaboratively in a fast-paced development environment.
