## Role summary (paraphrased from the posting)

GAMURS runs a network of around 15 websites, most on WordPress, plus tools, APIs and products for gaming and fandom communities. The developer takes technical ownership across that network, working mainly on WordPress (PHP) and Cloudflare: owning and evolving the WordPress platform across the sites (themes, plugins, custom post types, shared infrastructure), building features end to end from scoping through deployment and monitoring, improving performance (Core Web Vitals, caching, edge optimization) and security (headers, WAF rules, hardening), maintaining internal tools, APIs and integrations, collaborating with Product, Editorial, Commercial and Syndication teams, and joining on-call rotations and incident response.

Requirements named: strong PHP and WordPress (custom themes, plugins, WordPress REST API); React and TypeScript; Cloudflare Workers, Pages and edge computing; web performance and security fundamentals; CI/CD pipelines and deployment automation (GitHub Actions preferred); effective use of AI coding agents; independent problem-solving in a remote environment; communication across distributed teams. Nice to have: Next.js, GraphQL and headless WordPress, MySQL query optimization, Docker and infrastructure-as-code, analytics / A-B testing / personalization.
